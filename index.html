¿Qué es CSS?

CSS es una herramienta útil, práctica y eficaz para el diseño de páginas web y el formato de textos, enlaces, imágenes y otros elementos.

¿Qué aprenderé en este curso?

Aprenderas a organizar y darle color a las paginas web.

¿Qué es CSS GRID?

Permite dejar atrás la problemática forma de crear diseños en CSS, aportando un modelo de cuadrículas o rejillas muy personalizable.
